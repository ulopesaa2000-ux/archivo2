# Scripts

Este directorio contiene scripts utilitarios del proyecto.

## Contenido

- `clean.js` - Script para limpiar archivos temporales
- `start-tunnel.ps1` - Script para iniciar túnel (PowerShell)

## Uso

```bash
# Limpiar archivos temporales
node scripts/clean.js

# Iniciar túnel (PowerShell)
./scripts/start-tunnel.ps1
```

## Notas

Estos scripts son parte de la herramienta del desarrollo y ayudan en tareas recurrentes.
