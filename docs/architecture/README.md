# Documentación de Arquitectura

Esta carpeta contiene documentos relacionados con la arquitectura y diseño del sistema.

## Contenido

- `fetch_schema.mts` - Script para obtener el esquema de la base de datos
- `temp_form.json` - Formulario temporal usado durante el desarrollo
- `metadata.json` - Metadatos del proyecto

## Notas

Estos archivos son parte del diseño y arquitectura del proyecto. Algunos pueden ser temporales y ser movidos o eliminados cuando ya no sean necesarios.
