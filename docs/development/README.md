# Archivos de Desarrollo

Esta carpeta contiene archivos de registro y documentos relacionados con el desarrollo del proyecto.

## Contenido

- `errors.txt` - Errores generales durante el desarrollo
- `errors_utf8.txt` - Errores en formato UTF-8
- `errors2.txt` - Errores adicionales
- `ts_errors.txt` - Errores de TypeScript
- `ts-errors.txt` - Errores de TypeScript (alternativo)

## Notas

Estos archivos son registros de errores y problemas encontrados durante el desarrollo. Se mantienen para referencia histórica y debugging futuro.
